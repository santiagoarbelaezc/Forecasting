1. iTransformer: Inverted Transformers

El problema no era el Transformer, sino cómo se aplicaba. iTransformer conserva intactos los componentes estándar del Transformer e invierte las dimensiones: cada variable completa se procesa como un token independiente, calculando atención multivariada entre variables y modelando el tiempo con la red feed-forward.

CONTEXTO & MOTIVACIÓN

1.1 La Paradoja de los Transformers en Series Temporales

¿Por qué modelos lineales simples superaban a arquitecturas complejas de atención en exactitud y costo?

En el pronóstico multivariado (MTSF), trabajos como Zeng et al. (2023) mostraron que capas lineales superaban a Informer, Autoformer o FEDformer. iTransformer responde que el problema no era el Transformer, sino el esquema tradicional de "token temporal" heredado del procesamiento de lenguaje (NLP).

1.3 LIMITACIONES DEL ENFOQUE CONVENCIONAL DE TOKEN TEMPORAL
1. Fusión de Variables Heterogéneas

Mezcla magnitudes físicas incompatibles (temperatura, voltaje, precio) en un mismo token por instante, perdiendo representaciones variate-centric.

2. Retardos no Alineados (Delays)

Valores registrados en el mismo timestamp no siempre corresponden al mismo evento físico causal. Forzar un token ignora desfasajes temporales.

3. Campo Receptivo Local Estrecho

Un solo timestamp contiene poca información por sí mismo para capturar tendencias o estacionalidad global.

4. Atención Invariante a la Permutación

La atención no tiene orden intrínseco. Aplicar un mecanismo permutation-invariant sobre el eje temporal desaprovecha la estricta naturaleza secuencial de los datos.

5. Degradación con Lookback Largo

Al agrandar la ventana histórica, el número de tokens crece disparando el costo $O(T^2)$ y empeorando el desempeño por sobreajuste.

TRANSPOSICIÓN CONCEPTUAL

1.5 Definición Formal: Invertir el Eje

En una serie multivariada con $T$ instantes y $N$ variables:

  • Transformer Convencional: cada fila (todas las variables en un instante) es un token. Secuencia de $T$ tokens.
  • iTransformer: cada columna (toda la serie histórica de una variable) es un token. Secuencia de solo N tokens.
X ∈ ℝT × N   ⟶   XT ∈ ℝN × T
Se intercambia el rol de "secuencia" y "variable" sin modificar las matemáticas internas de atención.
INVERTED EMBEDDING

1.8.2 Incrustación Invertida

Cada variable dispone de un vector de longitud $T$ con su historial completo. Un MLP proyecta individualmente cada serie $X_{:, n} \in \mathbb{R}^T$ a la dimensión del modelo $D$ ($d_{model}$):

hn0 = Embedding(X:, n) ∈ ℝD   ⟹   H0 ∈ ℝN × D

Sin codificación posicional temporal: el historial completo constituye la entrada del embedding y el orden temporal queda intrínsecamente aprendido en la representación del token.

Ejemplo: 96 observaciones y 7 variables ($7 \times 96$) $\to$ 7 tokens de dimensión $D$ ($7 \times D$).

ARQUITECTURA INTERNA

1.8 Componentes del Bloque Codificador iTransformer

El codificador se organiza alrededor de dos transformaciones fundamentales con conexiones residuales y LayerNorm.

1.8.3.1 Autoatención entre Variables

N × N

Como cada token representa una variable completa, la atención calcula relaciones estadísticas mutuas (multivariate correlations):

Attention(Q, K, V) = softmax( (Q·KT) / √dk ) · V

El producto $QK^T$ genera una matriz $N \times N$ donde cada elemento refleja el grado de correspondencia entre pares de variables.

H̃l = LayerNorm(Hl-1 + SelfAttn(Hl-1))
No implica causalidad física, sino correlaciones estadísticas aprendidas.

1.8.3.2 Red Feed-Forward (FFN)

Temporal-Wise

Se aplica de forma compartida e independiente sobre cada token de variable, transformando su información temporal global:

FFN(h) = W2 · σ(W1·h + b1) + b2

Sus neuronas actúan como filtros capaces de codificar implícitamente amplitud, periodicidad o espectro de frecuencias de la serie.

Hl = LayerNorm(H̃l + FFN(H̃l))
Mantiene la dimensión $N \times D$ para el siguiente bloque.
APILAMIENTO

1.8.4 Apilamiento de Bloques Codificadores

El bloque Transformer invertido se repite L veces ($H^l = \text{TrmBlock}(H^{l-1})$). Construye representaciones progresivamente más elaboradas sin alterar la cantidad de variables $N$.

HL ∈ ℝN × D
PROYECCIÓN FINAL

1.8.5 Proyección de Salida e Interpretación

Una capa estrictamente lineal (Linear layer) proyecta de dimensión $D$ al horizonte $S$. Luego se transpone para recuperar la forma temporal:

Ŷ = Linear(HL) ∈ ℝN × S   ⟹   ŶT ∈ ℝS × N

Comparación entre Operaciones de Transformers

Reasignación de funciones: cómo cada componente hace exactamente aquello para lo que fue concebido.

Operación Transformer Convencional iTransformer
Auto-atención Relaciona pasos de tiempo entre sí ($T \times T$). Relaciona variables entre sí ($N \times N$).
Red feed-forward (FFN) Se aplica, de forma compartida, a cada token temporal (mezcla de variables). Se aplica, de forma compartida, a cada token de variable (una serie temporal completa).
Normalización de capa (LayerNorm) Normaliza los valores de todas las variables de un mismo instante. Normaliza la representación completa de cada variable sobre sus $D$ dimensiones.
Conclusión de los Autores: La atención, diseñada para descubrir relaciones en conjuntos no ordenados, modela variables; mientras que la FFN modela la evolución temporal univariada con la misma eficacia comprobada de los modelos lineales.
